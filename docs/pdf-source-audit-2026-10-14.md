# 已下载PDF数据来源审计｜2026-10-14

本轮核对46个Zotero条目，涉及45项既有研究及1份同研究工作论文版本。按学校/团队、原文声明、供应商、数据形态与证据页更新简记。原有人工备注、分类及PDF均保留。

- 41个条目确认实际使用具名数据源（对应40项研究）。
- 3个条目仅有补充材料，不能据此标为正文审阅完成；其中既有用户确认的Spectus关联予以保留。
- 1篇正文供应商仍未具名。
- 1篇CDR综述从待核使用案例中移出，保留为背景文献。
- 18项研究从05待核转入03；03由58增至76，05由42降至23。04泛先锋34项不变。
- 《Using Smartphone Location Data for Strategy Research》按正式版纠正为2025年；NBER旧版不重复计数。

## 关键归类修正

- Fulton County疫情移动论文：Advan Monthly Patterns为移动数据，SafeGraph仅提供POI。
- Fine-grained data reveal…：Veraset为移动数据，SafeGraph为POI辅助。
- Behaviour-based dependency networks…：Spectus为移动数据，SafeGraph为POI辅助。
- Do human mobility network analyses…：Spectus、X-Mode、Veraset均实际使用。
- Disaster vulnerability in road networks…：Cuebiq；原子简记中的Spectus/Veraset仅来自背景举例。
- Descartes Labs的地域聚合指标、SafeGraph的Social Distancing Metrics与Patterns、Veraset定位点/停留轨迹分别标注，不统一写成个人原始GPS数据。
