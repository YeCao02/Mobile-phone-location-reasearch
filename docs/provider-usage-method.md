# 供应商文献使用量：计数方法

本表是当前文献目录的证据下界，不能据此推断整个学科的使用率或市场份额。

计数单位为“去重研究 × 供应商展示组”。每一对只落入实际使用、仅提及、待核候选之一。具体证据链接及章节保存在provider_usage.json的associations中；同一论文可以使用多个来源，因此不同供应商数字不可相加为论文总数。

实际使用按角色分别计数：手机位置或派生流、POI库、数据分发渠道。谷歌公开位移统计及Octotelematics车辆GPS属于边界来源，必须结合scope字段阅读。SafeGraph为L20提供POI，Advan提供访问数据，Dewey为分发渠道；L06的Foursquare仅为场所库。L20引用文献中的Veraset不纳入供应商提及计数。

未复核全文的旧供应商标签全部进入待核候选，不自动认定实际使用，综述里的旧品牌标签亦如此。尚未识别供方的研究留在unassigned_papers，继续可见。

Cuebiq/Spectus沿用目录展示组，同篇一次计数、保留原文名称；这不是法律实体合并认定。先锋、Moxing、即刻LBS保持独立：Xia的方法供方为Moxing，先锋域名仅形成原文访问联系证据，会议摘要明确使用Jike数据，单独列为待核实体；与即刻LBS的映射仅列候选，不能自动合并。用户提供的关联关系不能把同一论文自动传播到三家。

L19和L05可计为两篇研究，但复用同一数据；L17也复用L02派生流。文章数不是独立面板数。零值表示本目录当前没有达到该证据门槛的记录，不能解释为供应商无人使用或从未被提及。
