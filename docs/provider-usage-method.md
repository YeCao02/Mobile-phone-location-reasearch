# 供应商文献使用量：计数方法

本表是当前文献目录的证据下界，不能据此推断整个学科的使用率或市场份额。

计数单位为“去重研究 × 供应商展示组”。每一对只落入实际使用、仅提及、待核候选之一。具体证据链接及章节保存在provider_usage.json的associations中；同一论文可以使用多个来源，因此不同供应商数字不可相加为论文总数。

实际使用按角色分别计数：手机位置或派生流、明示网络/基站混合定位、POI库、平台聚合与数据分发渠道。L29及刻数据明确SDK与网络/基站定位，单列mixed_mobility，不计入mobility或纯GPS/WiFi核心。L30百度慧眼为platform_aggregate；L32百度线索仅从继承标签进入待核。谷歌公开位移统计及Octotelematics车辆GPS属于边界来源，必须结合scope字段阅读。SafeGraph为L20提供POI，Advan提供访问数据，Dewey为分发渠道；L06的Foursquare仅为场所库。L20引用文献中的Veraset不纳入供应商提及计数。

未复核全文的旧供应商标签全部进入待核候选，不自动认定实际使用，综述里的旧品牌标签亦如此。尚未识别供方的研究留在unassigned_papers，继续可见。

Cuebiq/Spectus沿用目录展示组，同篇一次计数、保留原文名称。会议摘要L26原文Jike实际使用已核，但未列域名；中文显示对应依用户2026-10-10确认。L29直接列isjike.com，官网品牌是及刻、页脚版权主体为广州市梦享网络技术有限公司；即刻保留为用户检索别名。L29的域名证据不反向证明L26属于同一法律实体，也不证明与先锋的股权或法人关系。先锋、摸星、即刻·及刻依用户人工核验合并为一个展示节点（user_confirmed_supplier_group）；这不构成工商关系认定。同组同篇仅计一次，确认使用优先于仅提及；原成员关联保留在member_associations和逐项evidence。L21实际使用mobility只计一次，其pioneer访问联系仍保留为mention_only证据角色，不升级。roles/role_counts用于汇总状态角色，evidence_role_counts补充各原始证据角色，各角色内按论文去重。L27的99%为用户主观评估，非统计估计；原文未披露供方，关系仍为待核。深大PM2.5会议摘要、期刊文和配套数据集归入同一团队专题，出版成果仍分别保存；数据集不额外算一篇论文。

L19和L05可计为两篇研究，但复用同一数据；L17也复用L02派生流。文章数不是独立面板数。零值表示本目录当前没有达到该证据门槛的记录，不能解释为供应商无人使用或从未被提及。
