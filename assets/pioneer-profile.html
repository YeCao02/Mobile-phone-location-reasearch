Pioneer Data · Moxing · Jike（梦享）

这里汇总先锋数聚、摸星与及刻（梦享）关联研究使用的手机定位产品。已核实论文包含手机系统内嵌 SDK、GPS / Wi-Fi / 蓝牙定位和场景识别；研究者取得的材料既可能是带设备标识的多源点位，也可能是服务商运行分析后返回的聚合结果。不同论文、年份与交付批次的规格应分别阅读。

终端采集

具名梦享论文描述与手机厂商合作，将 SDK 嵌入手机系统，并在用户同意许可后获取位置。[2][3]

多源定位与场景识别

GPS 定时记录与 Wi-Fi 连接、稳定停留、场景指纹记录共同形成观测；各类型的触发条件不同。[1][4]

点位、停留与画像

通过设备标识关联时间、经纬度、来源类型及可用的 POI / 停留区间；部分产品另提供推断的职住地和人群标签。[1]

交付与研究

清洗点位后构建停留、访问或出行链；也有由服务商执行研究代码、仅返回聚合结果的交付方式。[1][5]

同一套多源交付中的四类记录

timing

GPS 定时点位

定位 / 触发
手机使用 / 亮屏等终端条件触发；记录间隔受厂商设置及设备活跃程度影响。
事件语义
点事件：该说明中 start_time 与 end_time 相同，不据此推断停留时长。

wificonnect

Wi-Fi 连接点位

定位 / 触发
用户主动连接已建库 Wi-Fi 接入点时上报。
事件语义
连接行为观测；不等同于所有到访者都会产生记录。

wifistable

Wi-Fi 稳定点位

定位 / 触发
在稳定网络环境中停留达到阈值；说明以 2 分钟以上描述。
事件语义
区间事件：提供开始与结束时间，需检查重复、重叠和漂移。

scenereco

场景识别点位

定位 / 触发
Wi-Fi、蓝牙及终端环境传感器信号与场景指纹库匹配。
事件语义
场景到访观测；识别能力取决于场景库与相应触发条件。

层级字段示例分析含义
关联键uuid / 脱敏设备 ID在获授权数据范围内连接同一设备的点位与可用标签。
时空观测时间戳 / start_time / end_time；经度、纬度区分瞬时点与持续区间，不能将点事件自动换算成停留。
来源与场景point_source；可用的 POI / 场景标识保留定位来源以进行分类型清洗、融合和可靠性检查。
派生产品职住地、人群标签、OD / 到访统计（依合同）属于规则或模型推断、分析输出；不等同于原始传感器观测。
