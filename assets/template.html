02 / DATA PRODUCTS

海外常用数据产品

SafeGraph · Veraset · Spectus / Cuebiq

海外常用位置数据：先分产品，再看供应商

同一供应商可能交付设备位置点、设备到访事件或地点聚合表。它们支持的研究尺度不同，不能仅凭公司名称把所有论文的数据视为相同。以下简介将历史研究版本与当前官方说明分开。

位置点 / ping设备 × 时间 × 坐标

适合自行识别停留、轨迹和暴露；采样间隔与有效覆盖需在研究样本内核验。

停留与到访 / stay、visit设备 × 停留区或POI × 时段

从位置点经聚类或地理围栏匹配生成；已包含供应商或作者的行为识别规则。

地点或区域聚合POI、CBG或区域 × 日、周、月

交付人数、次数、来源分布或OD；通常不能还原每个设备的完整轨迹。

以地点为中心的聚合到访；早期论文也用过设备位置点

SafeGraph · 历史 Patterns

数据形式
研究常见 Weekly / Monthly Patterns 的 POI 聚合到访；早期论文也用过设备级位置点。Core Places 则是地点属性表。[1][3][4]
结构与粒度
Patterns 按 POI × 周/月组织，含到访次数、访客数、逐日访问、居住 CBG 分布和停留时长。[1][3]
生产方式
获准共享的应用位置点经停留识别、POI 匹配和居住区推断后聚合；部分字段加噪并抑制小样本。[1][4]
覆盖与版本
历史月度产品面向美国，周度还含加拿大。Advan 于 2022 年收购 Patterns，2023 年初起原文档标为 legacy；旧研究须保留数据年份。[1][2][3]

Analysis of mobility data to build contact networks for COVID-19 ↗

Movement交付设备位置点，Visits交付设备—POI到访

Veraset · Movement / Visits

数据形式
Movement 是经预处理的设备位置点；Visits 是设备—POI 到访。两者均须与地点总客流聚合表区分。[1][3]
结构与粒度
Movement 围绕设备、坐标和时间组织，带水平精度等质量信息；Visits 关联设备与 POI。字段以采购版本字典为准。[2][3][4]
生产方式
上游包括 apps、SDKs 与 aggregators；Movement 按日交付，Visits 将 GPS 信号与地点多边形匹配。交付频率不等于定位频率。[1][3]
覆盖与版本
当前 Movement 面向全球，Visits 文档描述美国 POI。论文的国家、时段、面板与筛选后样本需分别记录。[2][3][4]
论文例证与来源
Proceedings of the National Academy of Sciences · 2021

Nursing home staff networks and COVID-19 ↗

Materials and Methods / Smartphone Location Data（PDF第5页）：Veraset汇集Apple/Android应用位置；此研究报告典型约10分钟一次ping，并自行用至少3个点、跨度至少1小时识别养老院访问。该频率和阈值属于本研究，不能推广至全部Veraset产品。

  1. Veraset Movement：上游与交付文档 ↗

Movement适合自行生成轨迹、停留与OD；使用Visits时需接受或检验供应商的POI匹配规则。

设备位置与停留分析，通常在受控数据平台中完成

Spectus / Cuebiq · 隐私增强位置与停留

数据形式
包括位置点、停留、居住区和派生 OD；Data Clean Room 是受控分析环境，不是一张固定数据表。[1][4][3]
结构与粒度
停留从时空聚类生成。美国居住/工作相关位置可上推至 CBG 质心，并过滤敏感 POI；变换坐标不是真实住宅位置。[2][1]
生产方式
应用获准共享后进入处理流程。Cuebiq 现行政策列 SDK 和 server-to-server，并明确 GPS 级经纬度及可行时的 Wi-Fi。[3][1]
覆盖与版本
已核论文包括美国全国和城市样本；国家、时窗与隐私规则均影响可分析范围。现行政策更新于 2026-08-21，不直接代替历史版本。[1]

04.1 / 数据从哪里来、怎样记录

泛先锋数据：从终端定位到场景与轨迹

Pioneer Data · Moxing · Jike（梦享）

这里汇总先锋数聚、摸星与及刻（梦享）关联研究使用的手机定位产品。已核实论文包含手机系统内嵌 SDK、GPS / Wi-Fi / 蓝牙定位和场景识别；研究者取得的材料既可能是带设备标识的多源点位，也可能是服务商运行分析后返回的聚合结果。不同论文、年份与交付批次的规格应分别阅读。

终端采集

与手机厂商合作，将 SDK 嵌入国行安卓手机系统，并在用户同意许可后获取位置。[1][2][3][6]

多源定位与场景识别

GPS 定时记录与 Wi-Fi 连接、稳定停留、场景指纹记录共同形成观测；各类型的触发条件不同。[1][4]

点位、停留与画像

通过设备标识关联时间、经纬度、来源类型及可用的 POI / 停留区间；部分产品另提供推断的职住地和人群标签。[1]

交付与研究

清洗点位后构建停留、访问或出行链；也有由服务商执行研究代码、仅返回聚合结果的交付方式。[1][5]

关联品牌与公司名称

按用户提供的供应商信息：及刻与先锋同一资方、同一数据来源，同时存在一定竞争关系；在本库中作为互相关联的品牌／“马甲”追踪。

先锋数聚一侧

先锋数聚（Pioneer Data）／北京先锋数聚信息科技有限公司；摸星科技（Moxing Technology、Moxing Beijing）。

及刻一侧

及刻（Jike、isjike.com）；梦享（广州市梦享网络技术有限公司，Guangzhou Mengxiang Network Technology Co., Ltd.）。

关联关系依据：用户提供信息；论文仍保留实际署名。

同一套多源交付中的四类记录

timing

GPS 定时点位

定位 / 触发
手机使用 / 亮屏等终端条件触发；记录间隔受厂商设置及设备活跃程度影响。
事件语义
点事件：该说明中 start_time 与 end_time 相同，不据此推断停留时长。

wificonnect

Wi-Fi 连接点位

定位 / 触发
用户主动连接已建库 Wi-Fi 接入点时上报。
事件语义
连接行为观测；不等同于所有到访者都会产生记录。

wifistable

Wi-Fi 稳定点位

定位 / 触发
在稳定网络环境中停留达到阈值；说明以 2 分钟以上描述。
事件语义
区间事件：提供开始与结束时间，需检查重复、重叠和漂移。

scenereco

场景识别点位

定位 / 触发
Wi-Fi、蓝牙及终端环境传感器信号与场景指纹库匹配。
事件语义
场景到访观测；识别能力取决于场景库与相应触发条件。
各类型精度、字段与适用范围

以下为用户提供的先锋交付说明口径，文档未标统一技术版本；数值属于该说明的精度描述，并非本知识库的独立精度测试。采购文件出现 timing / link / stable / poi，交付说明使用下列名称；具体字段映射以对应批次字典为准。[1]

点位供应商说明精度常见用途
timing约 50 m连续轨迹、空间活动与职住推断的基础观测。
wificonnect5–10 m连接场所定位与到访辅助识别。
wifistable15–20 m停留识别、活动时长及日内行为分析。
scenereco2–3 m商场、枢纽、轨道站点等已覆盖场景的精细到访研究。
层级字段示例分析含义
关联键uuid / 脱敏设备 ID在获授权数据范围内连接同一设备的点位与可用标签。
时空观测时间戳 / start_time / end_time；经度、纬度区分瞬时点与持续区间，不能将点事件自动换算成停留。
来源与场景point_source；可用的 POI / 场景标识保留定位来源以进行分类型清洗、融合和可靠性检查。
派生产品职住地、人群标签、OD / 到访统计（依合同）属于规则或模型推断、分析输出；不等同于原始传感器观测。
