01 / EVIDENCE FIRST

先分清三个层次

研究有效性取决于原始观测、数据加工和作者实际使用的材料。

COLLECTION

应用来源 ≠ SDK 明示

SDK 描述采集软件机制；GPS、WiFi 描述定位技术。论文仅写 GPS，不足以排除操作系统的蜂窝辅助定位；这也不等于外购运营商信令。

PRODUCT

品牌 ≠ 轨迹产品

同一品牌可销售 POI、访问模式、设备轨迹与模型估计。记录具体产品、数据年份、供应关系和研究者实际获得的数据形态。

VERIFICATION

全文阅读 ≠ PDF ≠ 附件

打开全文并读到关键段，不能自动标记为 PDF 已下载或 Zotero 已附全文。三项状态独立核实。“本轮未核验”不代表没有文件或附件；缺少记录时单独标注。

本库是阶段性定向检索结果。未命中不代表不存在；当前样本不能证明 SafeGraph 是学术使用最多的供应商，也不能用于供应商市场份额比较。

文献与获取路径

  1. 补读当前未审查全文的记录，分别记录正文、补充材料、下载文件和 Zotero 附件状态。
  2. 从机构授权访问渠道验证具体出版社和 DOI；浏览器可访问不自动证明脚本或整机网络已接管。
  3. 扩展污染与热暴露、旅游、零售、职住及就业研究，按 DOI 去重并标注数据复用关系。
  4. 公开库只保留书目信息、证据摘要与合法来源链接，不包含论文全文 PDF。
