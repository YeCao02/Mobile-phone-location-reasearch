# 手机定位数据研究知识库

当前网页按三类浏览：

- **03 数据供应商类似物**：按供应商展示确认使用的研究，紧凑卡片突出供应商、题名和期刊；名录同时保留尚无确认论文的供应商。
- **04 泛先锋相关联数据 · 已确认**：只展示已确认的 Pioneer / Moxing / Jike 研究，按学校—团队组织；采购与基金单列。
- **06 未确认内容**：全部未具名、间接关联或待全文核验的研究集中在此，可按泛先锋候选、正文与PDF状态筛选。

原04B及已确定不相关的地图商、基站等边界来源不再展示。底层书目和来源档案保留，未删除历史研究记录。图表折叠于01，统计当前三类文献。缺少PDF不会把已确认来源的研究降为待确认。


**在线浏览：[移动位置研究图谱](https://yecao02.github.io/Mobile-phone-location-reasearch/)**

应用与 SDK 手机定位数据的供应商、文献、采购及科研证据知识库。中文响应式静态网页，可按关键词、准确期刊、人工归类的研究领域、供应商、审查状态、阅读状态、PDF 下载、Zotero 附件、来源确认程度和年份检索。每张文献卡分开记录采集机制、数据形态、方法及证据来源。

## 浏览与重建

直接打开 `index.html` 即可离线浏览；所有样式、脚本和展示数据均内嵌，不需要网络加载依赖。打开证据链接仍需联网。

使用 Python 3 重建：

```sh
python build_site.py
```

构建器读取 `data/global_providers.json`、`data/china_evidence.json`，文献优先使用全量去重目录 `data/literature_catalog.json`；目录缺失时回退到 `data/literature_evolution.json`。继承候选保留为 pending 并默认展示，已审查条目保留 reviewed。指定其他来源目录：

```sh
python build_site.py --data-dir path/to/evidence
```

本地研究工作目录允许回退到相邻 `agents` 目录；公开仓库应将可发布数据放入 `data`，再重建并提交生成的 `index.html`。模板为 `assets/template.html`，修改模板后必须重建。构建器仅导出明确允许的公开字段，不导出本地工作上下文；任何新增字段应先检查再加入。

## 发布 GitHub Pages

1. 将本目录中的网站文件提交到目标仓库的发布分支根目录。
2. 在 GitHub 仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**。
3. 选择实际发布分支及 **/ (root)**，保存。
4. 等待部署完成，访问 GitHub 给出的站点地址并检查搜索、筛选及来源链接。

2026-10-10 已完成首次发布，GitHub Pages 返回 built，线上页面已实测。后续更新仍以对应部署结果及可访问页面为准。网站不需要第三方分析、API 密钥或登录凭据。

## 证据边界

- 定向样本不是穷尽性系统综述，也不是供应商市场份额统计。
- 品牌、SDK、定位传感器和作者得到的数据产品是不同字段。
- `fulltext_read` 仅表示全文关键段已读，不等于逐句读完、下载 PDF 或核验 Zotero 全文附件。
- `pdf_downloaded` 和 `zotero_attachment_verified` 为 true 时表示已核验；false 表示“本轮未核验”，不表示确定没有文件或附件；字段缺失显示“缺少核验记录”。两项不会从阅读状态推断。
- 摸星北京属于先锋体系为用户确认信息；公开工商、法人和品牌关系仍待补证。
- 采购、基金、论文分别取证；未检索到证据不表示关系不存在。
- 不发布论文全文、用户本地路径、VPN 网络信息、认证信息或个体轨迹。

更新台账后重建网页，保留来源 URL、证据范围与核验日期。详情点击展开可查看原始证据链接。

全量目录提供 JSON 与 CSV 下载；`data/acquisition_queue.json` 保存逐篇获取入口、当前状态及下一步。

## 浏览图表与待办

- 默认显示当前有效文献，包括继承候选；可切换为“仅已审查文献”。人工排除记录保留在排除档案，不进入当前列表、图表、供应商计数或获取队列。已审查和全文已读分别计数。
- 年份、期刊、研究领域图表直接统计当前范围。每根柱标出实际条数；缺失元数据单独计入待核验类别。期刊按准确刊名统计，不把 Nature 子刊合并成 Nature。
- 点击柱或条形可筛选下方文献，可叠加选择；再次点击同一项取消选择。图表保留当前范围的全貌，列表显示筛选结果。
- 研究领域是人工归类的主要方向，不等同于期刊官方学科分类。
- 会议摘要与预印本明确标出文献类型；出版页面已列出但登记待核的 DOI 保留题录说明。
- 期刊、发表年份及供应商在文献卡片展开前可见；详情提供证据、获取状态、出版社入口和下一步。
- 待办入口涵盖继承候选、已审查但待补读全文、待核验 PDF 及待核验 Zotero 附件。候选也始终存在于完整文献列表。

## 供应商与论文统计

供应商区读取 `data/provider_usage.json` 的逐篇关联证据，分别展示“确认使用”“仅提及”和“关系待核”。每个供应商—论文组合只计一次，同一论文可对应不同供应商，因此供应商数量不可相加作为论文总数。0 仅表示本库未确认。

移动定位、POI、平台聚合位置、车辆 GPS、分销渠道、获取联系方与方法比较参考按数据角色分别过滤，车辆和平台聚合数据不会自动归为应用 SDK 定位。默认只展开本库已有论文关联的供应商，无关联节点可通过按钮或公司名搜索查看。供应商档案与产品谱系收于二级展开区，先锋数聚、摸星、即刻／及刻／Jike按用户人工确认合并为关联展示组，保留原文名称并按论文去重。点击数字以关联表中的确切论文 ID 过滤文献，能够与期刊、年份、研究领域等条件叠加；再次点击同一数字或文献区的关联标签取消该条件，“清空”恢复全部。
