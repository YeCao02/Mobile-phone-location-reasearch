## 统计口径

历史目录160条：主页面131条，另有19条边界来源和10条排除记录。主页面含1条会议摘要，因此年度图为130篇论文与预印本；期刊领域图进一步排除9篇会议论文和1篇预印本，分母为120。

精选刊物图按明确刊名清单统计：Nature、刊名以 Nature 开头的期刊、PNAS 和 Science，共8刊17篇；分母为这些刊物内的论文数，不是全部120篇，也不是影响因子排名。

图表支持全部、已确认、泛先锋、类似供应商和待核5个范围。其统计范围独立于主页的文献关键词搜索。期刊领域为按刊物主要方向形成的编辑分类，不是JCR分区，也不是论文研究主题。2026年为截至10月13日的收录量，本图不代表全领域发文量。

## 数据与证据边界

“泛先锋”是本库按用户确认与论文证据组织的关联研究组，不表示每个品牌、法律实体和历年产品完全相同。GPS、Wi-Fi和SDK并非某一公司独有，比较应落在记录触发、数据字段、空间粒度和交付方式。产品介绍保留论文历史版本与当前官方说明的区别。

采购、基金和论文分别取证。是否取得PDF与供应商是否确认单独记录。个人轨迹、全文PDF、Zotero认证信息和本地文件路径不发布。

## 构建与复核

网站主页面从 `assets/template.html` 和 `data` 中的公开目录重建：

```sh
python build_site.py
node docs/smoke-test.js
node docs/scope-screening-test.js
```

部署需保留 `assets/`、`data/` 与 `literature-analytics.html`。主页面使用本地资源；图表为Data Analytics原生图表生成的自包含HTML。证据链接需要联网。

图表规范和有界数据保存在 `data/literature-analytics-artifact.json`，计数的SQL与Python核对程序分别在 `data/literature-counts.sql` 和 `data/literature-counts.py`。更新目录后应同步更新统计快照，不能只重建主页面。

此次图表打包验证通过；打包器的独立无头浏览器不可用，静态SVG提取未完成。另已在实际浏览器核对增强图表显示及范围筛选。未运行的移动视口检查不视为通过。

[历次研究、分类和附件核验记录](docs/)作为历史快照保留；其中旧轮次的数量和导航编号不代表当前版本。
